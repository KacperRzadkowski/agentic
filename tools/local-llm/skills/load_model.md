# Load Model
This skill provides access to the `load_model` handler in `llm_tools.py`.

## Description
Loads a specific model into LM Studio's inference engine so it can be used for chatting or completions.

## Usage
Call the `load_model(model_id)` method of the `LLMTools` class, where `model_id` is the identifier of the model you want to load.

## CLI Command
`lms load <model_id>`
