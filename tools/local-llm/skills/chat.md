# Chat
This skill provides access to the `chat` handler in `llm_tools.py`.

## Description
Sends a single prompt to a model (using `lms chat --prompt <prompt>`) and returns the response.

## Usage
Call the `chat(prompt, model_id=None, system_prompt=None)` method of the `LLMTools` class.

## CLI Command
`lms chat --prompt "<prompt>"`
