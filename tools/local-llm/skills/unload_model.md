# Unload Model
This skill provides access to the `unload_model` handler in `llm_tools.py`.

## Description
Unloads a specified model from memory to free up system resources.

## Usage
Call the `unload_model(model_id)` method of the `LLMTools` class, where `model_id` is the identifier of the model you want to unload.

## CLI Command
`lms unload <model_id>`
